# Architecture

StarMap loads `DevPanelMod` from the isolated profile manifest. The BeforeMain callback verifies the host build, API and effective documents path, then creates the run marker. AfterGui samples live state and passes an immutable vessel snapshot to the workbench. The snapshot is replaced on every draw. The adapter owns all live game reads.

Session diagnostics hold bounded, structured events and format a compact clipboard report. The workbench owns the hotkey and layout. Settings are stored in the verified isolated profile. The mod has no gameplay commands and adds no Harmony patches of its own.

## Performance sampling

`PerformanceSampler` polls once per second on a background task and publishes immutable snapshots for the UI. `PerformanceHistoryBuffer` retains a bounded five-minute in-memory series and emits null gaps for missing readings. The metric picker opens a single-metric ImPlot view with current/minimum/maximum and elapsed-time history; its ImPlot signatures were inspected against the local `.5949` BRUTAL references (L-01, locally inspected). `SystemMetricsCollector` reads process CPU time, host CPU times, process memory, managed heap estimate, system RAM and the OS-reported average current CPU frequency across active processors. `GpuMetricsCollector` reads the current process's Windows GPU Engine counters through PDH, then attempts to match the counters' adapter LUID with a DXGI adapter before showing its name or querying process video-memory usage and budget. The sampler releases PDH/DXGI handles on unload. Missing or unsupported metrics remain unavailable rather than displaying zero. These Windows API contracts are documented under source ID D-PERF. Process CPU graph rendering was observed in the isolated `.5949` runtime; hardware readings and local Vulkan video-memory accuracy still need validation.
