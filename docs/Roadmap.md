# Roadmap

The workbench starts with Runtime Console and Vessel Inspector. The Performance tab now includes once-per-second process/system sampling and selectable five-minute metric graphs; hardware-specific validation remains pending.

Universe Inspector comes next, starting with a searchable body hierarchy. Later candidate panels include UI Inspector, Simulation Controls, Configuration Manager, and Codex Bridge. A deeper Performance Profiler with frame-time analysis and longer capture sessions remains a separate future feature.
